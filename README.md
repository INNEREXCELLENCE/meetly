# Meetly Live

실제로 실행 가능한 공유 일정 조율 웹앱입니다. Node.js 기본 HTTP 서버만 사용하므로 별도 npm 패키지가 필요 없습니다.

## 실행
1. Node.js 18 이상 설치
2. 이 폴더에서 터미널 실행
3. `npm start`
4. 브라우저에서 `http://localhost:3000`

## 기능
- 새 일정 생성
- 일정별 고유 공유 링크
- 링크를 붙여넣어 일정 참여
- 참여자별 가능 시간 저장
- 3초 주기 실시간 동기화(폴링)
- 참여율 히트맵
- 시간 클릭 시 가능한/불가능한 사람 확인
- 불가능한 사람 클릭 시 해당 사람의 가능 시간 강조
- 빠른 선택 ON/OFF
- JSON 파일 기반 영속 저장 (`data/events.json`)

## 인터넷 공개
로컬 실행과 인터넷 공개는 별개입니다. 인터넷 공개 시 Node 서버를 HTTPS 지원 호스팅에 배포하고, 운영 환경에서는 JSON 저장소 대신 PostgreSQL/Supabase 같은 DB를 권장합니다.
